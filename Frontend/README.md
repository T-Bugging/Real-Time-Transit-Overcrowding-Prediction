UDAY Bus — Frontend (React + Vite)

Quick start:

1. Install dependencies:

```bash
cd Frontend
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes:
- This project uses mock API functions in `src/api/mockApi.js`.
- Map is centered on Nagpur (lat 21.1458, lng 79.0882) using Leaflet/OpenStreetMap.
- The frontend expects real backend endpoints under `/api/*` — for now it uses mocked data.
